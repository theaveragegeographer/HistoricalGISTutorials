# Historical GIS Tutorials

A comprehensive textbook and repository for learning Geographic Information Systems (GIS) techniques for historical research and analysis.

## Overview

This repository provides hands-on tutorials and resources for historians, archaeologists, and digital humanities scholars interested in using GIS techniques for spatial analysis of historical data. Learn to work with digital historical geography resources and create meaningful visualizations and analyses of historical phenomena.

## Key Resources Covered

- **Digital Atlas of Roman and Medieval Civilization (DARMC)**: Explore Roman and medieval geography with comprehensive spatial datasets
- **MormonPlaces**: Work with historical Mormon settlement and migration data
- **Historical Map Collections**: Learn to georeference and analyze historical maps
- **Open Historical Data**: Discover and utilize various sources of digital historical geography

## Prerequisites

- Basic understanding of historical research methods
- Familiarity with spreadsheets and data organization
- Interest in spatial analysis (no prior GIS experience required)

## Software Requirements

The tutorials in this repository primarily use:
- QGIS (free and open-source)
- Web-based GIS platforms
- Basic data manipulation tools

Installation instructions are provided in the [Getting Started](./tutorials/01-getting-started.md) guide.

## Learning Objectives

By completing these tutorials, you will:
- Understand fundamental GIS concepts and their application to historical research
- Learn to find, evaluate, and use digital historical geography resources
- Create maps and spatial visualizations of historical data
- Perform spatial analysis to answer historical research questions
- Develop skills in georeferencing historical maps
- Work with various data formats and coordinate systems
