# Data Sources and Resources for Historical GIS

## Introduction

This comprehensive guide provides access to the wealth of digital historical geography resources available for your research. Learn where to find data, how to evaluate it, and how to use it effectively.

## Major Digital Historical Geography Resources

### 1. Digital Atlas of Roman and Medieval Civilization (DARMC)

**URL**: https://darmc.harvard.edu/

**Coverage**: Ancient Mediterranean and medieval Europe

**Data types**:
- Settlement locations
- Road networks
- Political boundaries
- Physical geography
- Infrastructure

**Format**: Shapefiles, KML, GeoJSON

**Access**: Free download, attribution required

**Best for**: Classical antiquity, Roman Empire, medieval Europe

**Documentation**: Extensive metadata, peer-reviewed

### 2. MormonPlaces

**Coverage**: Latter-day Saint historical sites (primarily 19th century North America)

**Data types**:
- Settlement locations with dates
- Migration routes
- Historical events
- Religious sites
- Biographical information linked to places

**Access**: Through Church History resources

**Best for**: 19th-century American religious history, westward expansion, settlement patterns

### 3. Pleiades

**URL**: https://pleiades.stoa.org/

**Coverage**: Ancient world (Mediterranean, Near East, Europe)

**Data types**:
- Place names (ancient and modern)
- Coordinates
- Attestations with dates
- Connections between places

**Format**: JSON, CSV, RDF

**Access**: Free, open linked data

**Best for**: Ancient place names, linking datasets, scholarly citations

**Features**:
- Community-driven
- Peer-reviewed
- LOD (Linked Open Data) compatible

### 4. Pelagios Network

**URL**: https://pelagios.org/

**Coverage**: Connected ancient world data

**Data types**:
- Gazetteer of historical places
- Annotated texts
- Images and maps
- Linked datasets

**Access**: Free, open data

**Best for**: Integrating multiple ancient world datasets, semantic web approaches

### 5. HGIS de las Indias

**URL**: http://www.hgis-indias.net/

**Coverage**: Spanish colonial Americas (16th-19th centuries)

**Data types**:
- Administrative boundaries
- Cities and settlements
- Population data
- Economic data
- Trade routes

**Best for**: Latin American colonial history, Spanish Empire

### 6. China Historical GIS (CHGIS)

**URL**: https://sites.fas.harvard.edu/~chgis/

**Coverage**: China from 222 BCE to 1911 CE

**Data types**:
- Administrative boundaries over time
- Settlement hierarchy
- Place names
- Historical capitals

**Format**: Shapefiles, access database

**Access**: Free download

**Best for**: Chinese history, long-term administrative change

### 7. Great Britain Historical GIS (GBHGIS)

**URL**: http://www.gbhgis.org/

**Coverage**: Britain from 1801

**Data types**:
- Census data
- Administrative boundaries
- Statistical data
- Demographic information

**Best for**: British social and economic history, Victorian era

## Evaluating Data Quality

### Questions to Ask

**Source**:
- Who created this data?
- What are their qualifications?
- What was the purpose?

**Methodology**:
- How was data collected?
- What sources were used?
- How were decisions made?

**Currency**:
- When was it created?
- Has it been updated?
- Is there a newer version?

**Accuracy**:
- How accurate are locations?
- What's the spatial resolution?
- Are there known errors?

**Coverage**:
- What area is included?
- What time period?
- What's included/excluded?

**Documentation**:
- Is metadata available?
- Are methods described?
- Can you cite it properly?

**License**:
- Can you use it for your purpose?
- Attribution requirements?
- Redistribution allowed?

### Red Flags

- No documentation
- Unknown source
- No date information
- Suspicious accuracy (too precise?)
- No contact information
- Broken links
- No updates in years (for ongoing projects)

## Data Formats

### Vector Formats

**Shapefile** (.shp + supporting files)
- Standard GIS format
- Widely compatible
- Has limitations

**GeoJSON** (.geojson)
- Web-friendly
- Human-readable
- Growing adoption

**KML/KMZ** (.kml, .kmz)
- Google Earth format
- Good for visualization
- Limited analysis capability

**GeoPackage** (.gpkg)
- Modern alternative to shapefile
- No file number limitations
- Single file

### Tabular Formats

**CSV** (.csv)
- Universal compatibility
- Requires lat/long for mapping
- Simple to edit

**Excel** (.xlsx)
- Common distribution format
- Convert to CSV for GIS use

### Raster Formats

**GeoTIFF** (.tif, .tiff)
- Standard georeferenced image
- Includes spatial reference

**JPEG/PNG** (.jpg, .png)
- Common image formats
- Needs georeferencing for GIS

### Database Formats

**GeoDatabase** (.gdb)
- ESRI format
- Rich functionality
- Requires specific software

**SQLite/SpatiaLite** (.sqlite, .db)
- Open source spatial database
- Flexible and powerful

## Working with Data

### Data Cleaning

Common issues:
- Inconsistent place names
- Missing coordinates
- Incorrect dates
- Duplicate entries
- Format inconsistencies

Tools:
- OpenRefine: Data cleaning
- QGIS: Spatial validation
- Python/R: Scripting solutions

### Data Integration

Combining multiple sources:
1. Ensure same coordinate reference system
2. Standardize attributes
3. Check for duplicates
4. Document provenance
5. Create metadata

### Data Citation

Always cite:
- Dataset creator
- Dataset title
- Version/date
- URL/DOI
- Access date

**Example format**:
> Harvard Center for Geographic Analysis. (2019). Digital Atlas of Roman and Medieval Civilization (Version 2.0) [Data set]. https://darmc.harvard.edu/

## Creating Your Own Data

### When to Create Data

When existing data doesn't exist or isn't suitable:
- Your specific research question
- Understudied region
- Novel interpretation
- New sources

### Process

1. **Source selection**: Choose reliable historical sources
2. **Data model**: Design structure (what fields, what geometry)
3. **Georeferencing**: Locate places (gazetteers, maps)
4. **Digitization**: Create points/lines/polygons
5. **Attribution**: Add historical information
6. **Validation**: Check accuracy
7. **Documentation**: Create metadata
8. **Sharing**: Consider depositing in repository

### Best Practices

- Document everything
- Use existing gazetteers when possible
- Indicate uncertainty
- Include source references
- Follow data standards
- Consider sharing
